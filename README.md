## 📌 Project Overview

Tibyan is an end-to-end smart healthcare platform designed to analyze clinical laboratory results, assist medical professionals in detecting health risks, and enable real-time diabetes subtype predictions. 

The platform connects three core environments:
* **Web Portal (`Tibyan web`):** Web interface for patient management, lab report processing, and analytical insights.
* **Backend Engine (`tibyan`):** Core application logic, database integrations, and API endpoints.
* **Machine Learning Pipeline (`models`):** Trained diagnostic models, feature engineering pipelines, and prediction scripts.
